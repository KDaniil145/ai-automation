# ParcelBot — инструкции для Codex

## Проект
- Репозиторий содержит учебный сервис ParcelBot
- Фронтенд находится в frontend/
- Исходный прототип создан в Figma Make
- Экспортированные workflow n8n находятся в workflows/
- Главная задача — реализовать рабочий интерфейс поверх существующего n8n API

## Источники
- Перед интеграцией API прочитай оба JSON из workflows/
- Считай конфигурации workflow первичным источником API-контракта
- Не выдумывай новые поля, эндпоинты и возможности сервера
- frontend/AGENTS.figma.md — исторические инструкции Figma Make, не правила для текущего окружения

## Разработка
- Используй React и TypeScript
- Сохраняй существующий визуальный стиль и обе темы
- Не переписывай интерфейс с нуля без необходимости
- Не изменяй бизнес-логику n8n без отдельного разрешения
- Не добавляй авторизацию, редактирование или удаление посылок
- Не используй localStorage как основное хранилище посылок в финальной версии
- Не добавляй зависимости без необходимости
- Не изменяй calculator.py

## Проверки
- Добавляй клиентские тесты для важных пользовательских сценариев
- Проверяй успешные ответы API, ошибки, загрузку и пустые результаты
- Проверяй защиту от повторной отправки запроса
- Запускай доступные тесты и production-сборку
- Не выдавай успешную сборку за доказательство правильной бизнес-логики

## Безопасность
- Не записывай API-ключи, токены и пароли в репозиторий
- Не отправляй тестовые записи в production без разрешения
- Не выполняй git commit, push, merge или удаление данных без разрешения
- Перед существенными изменениями изучай затрагиваемые файлы

## Отчёт
- Кратко объясняй существенные изменения
- Перечисляй изменённые файлы
- Показывай, какие проверки действительно выполнены
- Отдельно сообщай о непроверенных сценариях и ограничениях
